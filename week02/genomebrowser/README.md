## Build a simple genome browser that can visualize the genome file and the annotation file.

This is just for fun for me. 

Obtained genomic data from the same organism as the visualizing genomic data assignment (*Genlisea aurea*). 

Use: 
```
make run
```
To run the Makefile and open the genome browser.
